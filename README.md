# SmartAttend — Smart Attendance System

**A dual-mode attendance system combining Facial Recognition and RFID technology.**

SmartAttend is an interactive web-based demonstration of a modern attendance management system designed to simplify attendance tracking, reduce manual effort, and provide an intuitive way to monitor attendance activity.

🌐 **Live Demo:** [Try SmartAttend](https://satyamthakur-coder.github.io/smartattend-demo/)

📂 **Source Code:** [GitHub Repository](https://github.com/SatyamThakur-coder/smartattend-demo)

---

## 🚀 Overview

Traditional attendance systems often rely on manual registers or a single identification method. SmartAttend demonstrates an alternative approach by bringing facial recognition and RFID-based attendance into one interface.

The demo allows users to explore attendance workflows, simulate recognition events, interact with RFID attendance controls, and view attendance logs and analytics.

## ✨ Features

### 📷 Facial Recognition Mode
- Interactive facial recognition demonstration.
- Simulated face detection workflow.
- Recognition controls and connection status.
- On-screen processing information.

### 📱 RFID Attendance Mode
- Interactive RFID reader simulation.
- Simulated card-tap attendance workflow.
- Reader activation and connection controls.
- Attendance event feedback.

### 📊 Attendance Logs and Analytics
- Live attendance activity log.
- Attendance log clearing and export controls.
- Report generation interface.
- Dashboard statistics for check-ins, recognition events, RFID scans, and offline synchronization.

### 🎨 User Interface
- Modern, interactive dashboard.
- Dedicated sections for features, analytics, and contact.
- Browser-based access through the live demo.
- Easy-to-explore attendance workflows.

## ⚙️ Getting Started

### Run the live demo

1. Visit the [SmartAttend Demo](https://satyamthakur-coder.github.io/smartattend-demo/).
2. Explore Facial Recognition Mode.
3. Use the simulation controls to test the recognition workflow.
4. Explore RFID Attendance Mode and simulate a card tap.
5. Review the attendance log and analytics dashboard.

### Run locally

Clone the repository:

```bash
git clone https://github.com/SatyamThakur-coder/smartattend-demo.git
```

Navigate to the project directory:

```bash
cd smartattend-demo
```

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
